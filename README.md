# The 15-Puzzle

This 15-Puzzle that can be run locally in your web browser by downloading the files or directly on the web.
<br />

There are 3 options:
1. Download the three files index.html, script.js, and style.css into on directory and run index.html (double-click the file or open the file in a web browser).
2. Download embed.html and run this file. embed.html contains all the tree other files in one file.
3. Run this puzzle on my website: [The 15-Puzzle](https://www.studio337.org/products/the-15-puzzle/solve-the-puzzle)
